# 配色主题

三套,在 `index.html` 的 `:root` 和 `:root[data-theme="..."]` 里。
切换靠 `<html data-theme="gala">`,`forge` 是 `:root` 本身的默认值,不设属性。

| 名字 | key | 底色 | 强调色 | 用在哪 |
|---|---|---|---|---|
| 暖炭 | `forge`(默认) | `#221C19` | 橙 `#FF8A1F` | 日常、稳重 |
| 年会红金 | `gala` | `#2B0F10` | 金 `#F3C44C` | 年会、春节。三套里对比度最高 |
| 墨蓝 | `ink` | `#1C212A` | 蓝 `#6FBBFF` | 偏商务、冷静 |

## 改配色的规矩

**先量对比度再提交。** 投影仪的实际对比度远低于手机屏幕,会场灯又不会全关,
所以标准定在 **正文 ≥ 7:1**(WCAG 的 AAA 线),而不是常见的 4.5:1。

`npm run test:theme` 会把三套主题的五组关键配对全量一遍:

- 大标题 `--bone` / `--slag`
- 次级文字 `--ash` / `--slag`
- 强调色 `--pour` / `--slag`
- 中奖卡上的名字 `--ink` / `--steel-lo`
- 卡片上的字 `--bone` / `--shell`

任何一组低于 7:1 就算失败。当前最低值:forge 7.1、gala 8.4、ink 7.9。

## 加一套新主题要改四个地方

1. `index.html` 的 CSS 里加一段 `:root[data-theme="xxx"]`,**13 个变量一个都不能少**
   (少了会继承默认值,出现半套红半套橙的样子)
2. JS 里的 `THEMES` 对象加一项(`bar` 是手机状态栏颜色,`zh` 是提示条里的名字)
3. `<head>` 里那段防闪代码的 `{forge:..., gala:..., ink:...}` 映射也要加
4. 设置面板的 `.themes` 里加一个按钮,`data-t` 对应 key

第 3 条最容易漏 —— 漏了的话重开页面会先闪一下默认色再变过来。

## 为什么不支持背景图

舞台大标题、奖项列表、总榜的分组标题都是**直接压在背景上**的文字
(中奖卡、滚动卡、总榜里每个名字都有自己的实色底,不受影响)。
照片一上去,这几处的对比度就从 13:1 掉到 3:1 上下,投影上基本看不清。
压暗到能看清的程度时,它看起来和纯色底也没什么区别了。
